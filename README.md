# LUCKY ROULETTE 🎰 — 도박중독예방교육용 체험 룰렛

학생(모둠)들이 코인을 걸어도 **결과는 진행자가 키보드로 몰래 정하는** "절대 이길 수 없는 룰렛"입니다.
모둠별 자산 관리, 수수료, 적금 기능이 있어 수업 한 차시를 게임으로 진행하고,
마지막에 "카지노가 가져간 코인"과 "적금만 했다면?"을 공개하며 마무리할 수 있습니다.

빌드 도구·외부 라이브러리·이미지 없이 순수 HTML/CSS/JS + SVG로 만들어져 있어 GitHub Pages에 그대로 올리면 동작합니다.

## 수업 전 준비

1. 사이트를 열고 **페이지를 마우스로 한 번 클릭**해 두세요.
   (브라우저 정책상 사용자 조작이 한 번 있어야 소리(틱·당첨음)가 납니다.)
2. `F` 키로 전체화면을 켜고 프로젝터(16:9)에 띄웁니다.
3. **게임 설정** 화면에서 모둠 수(기본 6), 모둠 이름, 총 라운드 수(기본 10), 시작 코인(기본 20)을 정하고 **게임 시작**.

## 라운드 진행 (매 라운드 3단계)

| 단계 | 진행자가 할 일 |
|---|---|
| ① 베팅 입력 | 모둠마다 **[베팅 / 적금 / 쉬기]** 중 하나를 고르고 입력 → **베팅 마감** |
| ② 룰렛 | 키보드 `1`~`8`을 누르면 룰렛이 돌다가 **그 숫자에 멈춤** |
| ③ 정산 | 자동 정산 결과(모둠별 +/− 증감) 확인 → **다음 라운드** |

### 한 라운드에 "베팅"과 "적금" 중 하나만!

각 모둠은 라운드마다 아래 셋 중 **하나만** 할 수 있습니다. 둘을 동시에 입력하는 것은 화면에서 아예 불가능합니다.

| 선택 | 입력하는 것 |
|---|---|
| 🎲 **베팅** | 번호(1~8)와 베팅 금액만 입력 (금액 제한 없음, 단 보유 코인 이하) |
| 💰 **적금** | 적금 금액(3/4/5/6) 하나만 선택 |
| 😴 **쉬기** | 아무것도 하지 않음 |

- 처음 기본 선택은 **쉬기**입니다. **적금이 진행 중인 모둠은 기본 선택이 "적금"**이고, 금액도 기존과 같은 금액으로 자동 채워집니다.
- 적금이 진행 중인 모둠이 **베팅·쉬기**를 고르거나 **적금 금액을 바꾸면** "○○모둠의 적금이 해지되고 보너스를 받을 수 없어요. 계속할까요?" 확인 창이 뜹니다.
  **해지하고 계속**을 누르면 그 라운드에 적금이 해지되고, **취소**(또는 `Esc`)를 누르면 원래 선택으로 돌아갑니다.
- 입력이 잘못된 줄(번호 미선택, 코인 부족 등)은 빨갛게 표시되고, 모두 고칠 때까지 **베팅 마감** 버튼이 잠깁니다.
- 룰렛 단계와 정산 단계의 현황판에는 모둠마다 무엇을 했는지 `🎲 3번 / 10코인`, `💰 적금 4코인 (2/3회)`, `😴 쉬기`처럼 표시됩니다.

## 키 조작법 (진행자 전용)

| 키 | 동작 |
|---|---|
| `1` ~ `8` (숫자패드 포함) | **② 룰렛 단계에서만** 동작. 룰렛이 돌다가 반드시 그 숫자 칸에 멈춤 |
| `F` (한글 입력 상태의 `ㄹ`도 가능) | 전체화면 켜기/끄기 (입력칸에 타이핑 중일 때는 무시) |
| `Space` / `Enter` | ③ 정산 연출 중에 누르면 연출을 건너뛰고 최종 결과를 바로 표시 |

- ① 베팅 입력 단계에서는 숫자키를 눌러도 룰렛이 절대 돌지 않습니다(입력칸에 숫자를 쳐도 안전).
- 키를 눌러도 화면에는 아무 표시가 나타나지 않습니다. 회전 중 입력과 키 반복 입력은 무시됩니다.
- 매번 5~7바퀴, 5~6.5초 동안 감속하며 칸 안의 무작위 위치에 멈춰 자연스럽게 보입니다.

## 정산 결과 연출

룰렛이 멈추고 당첨 칸 깜빡임이 끝나면 모둠별로 0.35초 간격으로 결과가 공개됩니다.

- **당첨**: 초록 번쩍 + `+20` 같은 초록 숫자 (3라운드부터는 이어서 `−2 수수료`가 빨간색으로 한 번 더)
- **낙첨**: 빨강 번쩍 + 흔들림 + `−10` 빨간 숫자
- **적금 만기**: 금색 번쩍 + `💰 만기 +18`
- 적금 납입·쉬기는 아주 약한 효과만, 보유 코인은 이전 값에서 새 값으로 롤링
- 코인이 0이 된 모둠은 회색 줄 + **파산** 표시
- 모든 연출이 끝나면 보유 코인 순으로 줄이 재정렬됩니다(다음 라운드 베팅 화면은 원래 모둠 순서).
- 연출 중에는 **다음 라운드** 버튼이 잠깁니다. `Space`/`Enter`로 건너뛸 수 있습니다.

## 정산 규칙

**당첨**: 베팅금의 2배(원금 포함)를 받습니다. 3라운드부터는 여기서 수수료를 뗍니다.
예) 10 베팅 → 20 받음 → (3라운드 이후) 수수료 2 → 실제 18 받음
**낙첨**: 베팅금을 잃습니다.

**수수료** (3라운드부터, 당첨된 모둠만 / 베팅 금액 기준)

| 베팅 금액 | 1~5 | 6~10 | 11~15 | 16~20 | 21~25 | 26~30 | 31 이상 |
|---|---|---|---|---|---|---|---|
| 수수료 | 1 | 2 | 4 | 5 | 7 | 8 | 10 |

**적금** (3, 4, 5, 6코인 중 선택)

| 매 라운드 납입 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|
| 3회 만기 시 받는 금액 | 9 + 5 | 12 + 6 | 15 + 8 | 18 + 10 |

- 3라운드 연속 같은 금액을 넣으면 3번째 납입 라운드의 정산 때 원금 + 보너스를 받습니다.
- 한 라운드라도 빠지거나(**베팅을 하거나 쉬는 라운드 포함**) 금액을 바꾸면 그 적금은 해지됩니다 → 보너스 없음, 원금은 **게임이 끝날 때** 돌려받습니다(현황판에 "보관 적금"으로 표시).
- 만기 후에는 새 적금을 다시 시작할 수 있습니다. 게임이 끝날 때 아직 만기 전인 적금도 원금만 돌려받습니다.

## 게임 종료 화면

- 최종 순위: 보유 코인 + 돌려받은 적금 합계 기준
- 룰렛의 진실: 전체 베팅 총액, 당첨으로 돌려받은 총액, 수수료 총액, **카지노(룰렛)가 가져간 코인**
- 베팅 없이 매 라운드 3/4/5/6씩 적금만 했을 때의 최종 코인과 우리 반 모둠 평균 비교
  (적금하는 라운드에는 베팅할 수 없으므로, "적금만" = 모든 라운드에 적금만 한 경우입니다. 예: 10라운드·시작 20코인·매번 6 → 50코인)

## 진행자 편의 기능

- **자동 저장**: 진행 상황이 브라우저(localStorage)에 저장되어 새로고침하거나 브라우저를 껐다 켜도 이어서 진행됩니다.
  (같은 컴퓨터·같은 브라우저에서만 유지됩니다.)
- **↶ 이전 단계로**: 입력 실수 시 한 단계씩 되돌립니다(정산 → 룰렛 단계로 되돌리고 다시 돌리기 등).
- **게임 초기화**: 버튼을 두 번 누르고 확인 창에서 한 번 더 확인해야 초기화됩니다.

## 파일 구성

- `index.html` — 화면 구조와 SVG 룰렛
- `style.css` — 카지노 스타일, 16:9 레이아웃, 애니메이션
- `roulette.js` — 룰렛 그리기, 회전 각도 계산, Web Audio 효과음
- `game.js` — 베팅·수수료·적금 정산 규칙 (화면과 분리된 순수 로직)
- `app.js` — 단계 진행, 현황판, 저장/되돌리기, 키보드 처리

## 로컬에서 실행

`index.html`을 브라우저로 열기만 하면 됩니다.
