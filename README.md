# LUCKY ROULETTE 🎰 — 도박중독예방교육용 체험 룰렛

학생들이 코인을 걸어도 **결과는 진행자가 키보드로 몰래 정하는** "절대 이길 수 없는 룰렛"입니다.
겉보기엔 무작위로 도는 것 같지만, 실제로는 운영자가 결과를 통제할 수 있다는 것을 체험시키기 위한 교육 자료입니다.

빌드 도구·외부 라이브러리·이미지 없이 순수 HTML/CSS/JS + SVG로 만들어져 있어 GitHub Pages에 그대로 올리면 동작합니다.

## 수업 전 준비

1. 사이트를 열고 **페이지를 마우스로 한 번 클릭**해 두세요.
   (브라우저 정책상 사용자 조작이 한 번 있어야 소리(틱·당첨음)가 납니다.)
2. `F` 키로 전체화면을 켜고 프로젝터에 띄웁니다.

## 키 조작법 (진행자 전용)

| 키 | 동작 |
|---|---|
| `1` ~ `8` (숫자패드 포함) | 룰렛이 돌다가 **반드시 그 숫자 칸**에 멈춤 |
| `F` (한글 입력 상태의 `ㄹ`도 가능) | 전체화면 켜기/끄기 |

- 키를 눌러도 화면에는 아무 표시도 나타나지 않습니다.
- 회전 중에는 키 입력이 무시되고, 키를 꾹 누르고 있어도 한 번만 동작합니다.
- 매번 5~7바퀴, 5~6.5초 동안 ease-out으로 감속하며, 칸 정중앙이 아닌 칸 안의 무작위 위치에 멈춰 자연스럽게 보입니다.

## 파일 구성

- `index.html` — 화면 구조와 SVG 룰렛
- `style.css` — 카지노 스타일, 전구·당첨 깜빡임 애니메이션
- `script.js` — 룰렛 그리기, 회전 각도 계산, Web Audio 효과음, 키보드 처리

## 로컬에서 실행

`index.html`을 브라우저로 열기만 하면 됩니다.
